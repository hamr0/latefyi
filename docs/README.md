# late.fyi documentation

Email-driven European train tracker. The full map of every doc, with line
counts and section anchors, is [`index.md`](index.md) (generated by
`/docs-builder`; never hand-edit it).

| Path | What lives here |
|------|-----------------|
| [`product/`](product/) | Core pages: the PRD ([`latefyi-prd.md`](product/latefyi-prd.md)), the operator runbook ([`cloudflare-setup.md`](product/cloudflare-setup.md)) and the email format catalogue ([`email-formats.md`](product/email-formats.md)) |
